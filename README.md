# OxyGen project website

This orphan branch contains the static project website for [OxyGen](https://github.com/air-embodied-brain/OxyGen). The site is built with Astro and has no runtime backend.

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` before submitting changes. The GitHub Actions workflow builds the site with the `/OxyGen` base path and deploys `dist/` to GitHub Pages.

Paper results and later extended validation are labeled separately on the page. Update measured values only from their cited project records.
