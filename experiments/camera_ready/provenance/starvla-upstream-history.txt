    * [deployment] EgoVLA G1 policy server: run EgoVLA in the red-ball sim
    
    Adds a GR00T-protocol policy server that serves the starVLA EgoVLA model on
    :5555 so the GR00T-WBC-Bridge -> Isaac-Lab G1 red-ball eval runs with EgoVLA
    as the policy (sim + bridge unchanged). Decodes EgoVLA's 48-dim camera-frame
    output into the bridge's joint-target contract:
    
    - arms: wrist EE pose (camera->pelvis via G1 D435 transform) -> 7-DoF joints
      by pinocchio DLS IK (g1_kinematics, FK-IK round-trip 20/20 <1mm), warm-started
      from state;
    - hand: MANO -> MANO FK -> fingertips -> HandActuationNet -> Inspire -> Dex3-7,
      per-finger (articulation preserved, so a commanded grasp is physically
      reachable — grasp success is up to the model, not capped by the wrapper);
    - base_height/navigate -> neutral.
    
    Only MANO forward kinematics is imported from EgoVLA (license-gated model); the
    rest is self-contained. License-gated assets (checkpoint, MANO .pkl, hand nets)
    are NOT committed — README documents the required downloads. Verified standalone:
    synthetic bridge obs -> valid GR00T action dict (arms 7-DoF, hand articulated).
    
    Files: server_egovla_g1.py, egovla_g1_policy.py, decode.py, g1_kinematics.py,
    g1_camera.py, assets/ (Unitree G1 URDF; hand nets git-ignored), README.md.
